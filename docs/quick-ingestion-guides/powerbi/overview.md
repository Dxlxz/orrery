# Power BI Ingestion Guide: Overview

## What You Will Get Out of This Guide

This guide will help you set up the Power BI connector to begin ingesting metadata into Orrery.

Upon completing this guide, you will have a recurring ingestion pipeline that will extract metadata from Power BI and load it into Orrery. This will include to following Power BI asset types:

- Dashboards
- Tiles
- Reports
- Pages
- Datasets
- Lineage

_To learn more about setting these advanced values, check out the [Power BI Ingestion Source](https://docs.orrery.dev/docs/generated/ingestion/sources/powerbi)._
