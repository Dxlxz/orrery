## Overview

OpenAPI is a documentation or collaboration platform. Learn more in the [official OpenAPI documentation](https://www.openapis.org/).

The Orrery integration for OpenAPI covers document/workspace entities and hierarchy context for knowledge assets. It also captures tags.
